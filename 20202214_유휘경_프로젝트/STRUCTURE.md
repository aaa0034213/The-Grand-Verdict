## 1. 파일 개요
*   **파일**: `index.html`
*   **방식**: HTML, CSS, JS가 모두 포함된 Single File Application (SPA 유사)
*   **외부 의존성**: Google Fonts (`Nanum Myeongjo`, `Gowun Batang`)

### ⚙️ Core Logic (JavaScript)

#### 1. 상태 관리 (`state` object)
*   `idx`: 현재 사건 인덱스.
*   `health`: 플레이어 체력 (기본 5개).
*   `sel`: 선택된 증거 ID.
*   `hints`: 남은 힌트 횟수.
*   `muted`: 오디오 음소거 여부.

#### 2. 주요 기능 함수
*   **UI/UX**:
    *   `startGame()`, `loadCase(i)`: 초기화 및 사건 로딩.
    *   `showModal()`, `showStamp()`, `showVictory()`: 각종 오버레이 및 연출.
    *   `typeWriter()`: 증언 텍스트를 한 글자씩 출력.
*   **Gameplay**:
    *   `doSearch()`: 입력된 쿼리로 `db` 배열 필터링 (Includes/Some).
    *   `select(id, row)`: 증거물 클릭 시 하이라이트.
    *   `objection()`: 정답 검증. 정답 시 진행, 오답 시 체력 감소.
    *   `useHint()`: 힌트 표시 및 카운트 차감.
*   **Audio & Voice**:
    *   `play(type)`: Web Audio API (`Oscillator`)로 효과음 합성 (click, slam, win, error 등).
    *   `speakWitness()`: Web Speech API (`SpeechSynthesisUtterance`)로 증언 TTS 출력. (한국어 음성 우선 선택 루틴 포함)
    *   `toggleMute()`: 모든 오디오 출력 제어.
